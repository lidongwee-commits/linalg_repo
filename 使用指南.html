二、怎么修改教材正文（讲解 / 案例 / 引例）

教材所有文字内容都集中在一个源文件里：

要改的文件： D:\linalg\线性代数数字教材.html
这是全站唯一的内容源，改它、再构建，五章网页就同步更新。
1
打开它：右键该文件 → 打开方式选「记事本」或「WPS 文字/Word」都行（用 VS Code 更好，但不是必须）。
2
找到要改的地方：按 Ctrl+F 搜索关键词（比如某道题的题号、某个小节标题），找到后直接改文字。
3
保存文件（Ctrl+S）。
4
发布：双击 1_构建.bat → 双击 2_部署.bat。
公式别乱拆： 教材里的数学公式用 \( … \)（行内）或 \[ … \]（独立成行）包住。如果你要改公式里的数字，只改数字、不要删掉那两个反斜杠括号。看不懂公式代码时，最好只改文字、不动 \(...\) 内部。
别删结构标签： 像 <h2>、<div class="case">、<details> 这类成对标签是页面骨架，误删可能导致构建报错或某节显示异常。只改"标签之间的文字"最安全。

三、怎么编辑习题 / 题库（推荐用后台，不用写代码）

网站里的选择题、填空题、计算题、证明题、应用题，都存在一个题库文件 exam_data.js（991 题）。改题库最省事的办法是用自带后台，完全不用碰代码。

方法 A：用 admin.html 后台（强烈推荐）

1
打开后台：双击 D:\linalg\admin.html（或在浏览器打开线上 …/admin.html，口令 teacher2026）。
2
找题：用页面上的搜索/筛选，按章节或题型定位。
3
改 / 加题：点某题的「编辑」改内容；或点「新增」加一道新题。选择题填选项 A/B/C/D，填空题/计算题填答案与解析。
4
导出：改完后点页面上的「⬇ 导出 exam_data.js」，浏览器会下载一个文件。
5
覆盖：把下载的 exam_data.js 复制到 D:\linalg\，替换掉原来的同名文件。
6
发布：双击 1_构建.bat → 双击 2_部署.bat。
后台改的题先存在浏览器缓存里。换电脑、清浏览器缓存前记得及时「导出」并覆盖文件，否则改动会丢。
如果双击 admin.html 后题目不显示：某些浏览器对本地文件较严格。改用"本地小服务器"打开——在 D:\linalg 文件夹里双击 1_构建.bat 同目录若没有服务器，可用 CMD 输入 python -m http.server 8000，再浏览器访问 http://localhost:8000/admin.html。线上网址方式则无此问题。

方法 B：直接改 exam_data.js（进阶，适合小批量微调）

题库文件 D:\linalg\exam_data.js 本质是一个大列表，每道题是一段 { … }。常见字段：

字段含义示例
"id"题目唯一编号（不能重复）"c1-hw-mc-1"
"ch"第几章1
"type"题型mc / fill / calc / proof / app
"sec"所属小节（决定"本节练习"里出现哪题）"s11"
"stem"题干"设 \\(D=m\\)，则 …"
"options"选择题选项（仅 mc 有）[["A","\\(2m\\)"],…]
"ans"答案"A" 或 "\\(2m\\)"
"fb"解析/解题过程文字，可含公式

加一道题：复制一道同类型题的整段 { … }，改里面的数字和文字，给一个不重复的 id，粘到列表里（注意前后用逗号分隔）。改完保存 → 双击 1_构建.bat → 2_部署.bat。

反斜杠铁律： 公式里的 LaTeX 命令在题库文件里必须是双反斜杠。例如要写 \neq，文件里要写成 \\neq；矩阵换行写成 \\[6pt]。少写一个反斜杠，公式会渲染出错。对照已有的题抄最稳妥。
千万不要： 不要为了"刷新题库"去运行 build_bank.py。那是早期从教材源一次性抽取习题的导入器，和线上题库是两回事；运行它会用教材里那份习题覆盖掉你精心维护的 991 题。日常只用 1_构建.bat 和 2_部署.bat。

五、学生端有哪些功能（方便你解答学生疑问）

① 恢复码同步——换设备不丢数据

学生在考试系统里做完题后，数据（错题本、成绩、能量值、掌握度）默认存在当前浏览器的 localStorage。如果换设备、清缓存，数据会丢失。为此我们做了恢复码同步功能：

1
在考试系统页面，点击顶部第 5 个标签「数据同步」。
2
点「生成恢复码」，系统会把当前学习数据编码成一串以 LAXD1. 开头的文本。
3
复制这串文本，保存好（发到自己的微信文件传输助手、邮箱草稿箱等）。
4
在新设备上打开考试系统 →「数据同步」→ 把恢复码粘贴进去 → 点「导入」，数据就会智能合并到新设备。
恢复码同步是零成本方案，不需要服务器和数据库，学生自己操作即可。能量值也会一并同步，多设备能量条保持一致。

② 二维码扫码——纸质教材联动数字练习

纸质教材每节末尾印有二维码，学生用手机扫码后会自动打开数字教材对应小节，并自动展开「学完就练」练习抽屉，无需手动翻找。每章末尾还有「本章测试」二维码，扫码直接进入在线测试。

扫码链接格式：网站地址/ch1.html?quiz=auto#s11
?quiz=auto 触发自动展开练习抽屉，#s11 定位到第 1 章第 1 节。

③ 手机端适配

教材章节页和考试系统均已适配手机浏览。学生在手机上打开网站，可以正常阅读教材、做练习、参加考试。考试系统在手机上会自动切换为竖版布局，题目和选项均可正常操作。

④ 能量柱——学习激励

学生完成「学完小节」「学完就练」「考试自测」「连击学习」均可获得能量值，右下角常驻能量柱实时显示。点击能量柱可查看成长详情（各章节掌握度柱状图、能量来源明细）。能量值通过恢复码同步实现多设备一致。

编译生成 PDF

1

2
打开 CMD，进入纸质教材目录：

3
编译（需跑两遍以生成目录）：
xelatex main.tex
xelatex main.tex
4
生成的 main.pdf 即为成品（约 182 页，含 33 个二维码）。

二维码命令

纸质教材中通过两个命令插入二维码，扫码后自动跳转到数字教材：

命令用法示例扫码效果
\practiceqr{章号}{小节号}{标题}\practiceqr{1}{11}{行列式的概念}打开 ch1.html?quiz=auto#s11，自动展开练习
\testqr{章号}\testqr{1}打开 exam.html?ch=1，进入本章测试
小节号不带 s 前缀！ 命令模板里已有 s，所以 \practiceqr{1}{11} 生成 #s11。写成 \practiceqr{1}{s11} 会变成 #ss11 导致定位失败。
网站域名变了怎么办？ 二维码里的网址定义在 preamble.tex 的 \ebookbase 命令里。只需改这一处，全书二维码自动更新。
